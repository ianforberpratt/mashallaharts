# Mashallah Arts

Website for Mashallah Arts — tea, candles, and handmade goods by Nargis Salmani Forber-Pratt, a small business registered in the State of Missouri.

Plain static HTML/CSS site, no build step required.

## Structure

- `index.html` — home page: shop, how to order, contact
- `story.html` — Nargis's full story
- `assets/style.css` — all styling
- `assets/` — put product photos and the logo here

## Local preview

Open `index.html` directly in a browser, or serve the folder:

```
npx serve .
```

## Deploying

This repo is set up to deploy as-is on [Vercel](https://vercel.com) (just import the repo, no build settings needed) or any static host (Netlify, GitHub Pages, etc).
